# Assignment Submission Portal

A web-based academic assignment submission system built using Flask, SQLite, and a CSV-based student registry.

##  Features

- Student assignment submission form
- Admission number validation using student registry (CSV)
- File upload support (PDF, PPT, PPTX)
- Automatic file organization per submission
- Lecturer admin dashboard to view all submissions
- SQLite database for structured storage
- Modern glassmorphism UI design

---

##  Tech Stack

- Backend: Flask (Python)
- Database: SQLite
- Data Processing: Pandas
- Frontend: HTML, CSS, JavaScript
- File Handling: Werkzeug
